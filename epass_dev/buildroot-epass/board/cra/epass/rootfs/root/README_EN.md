Files in this directory are installed into:

```text
/root/
```

on the target device. They provide the post-login startup logic, the terminal character-art logo, and fixed resources used by the main program. The CRA Electric Pass executable `/root/epass_drm_app` is not stored in this source directory; the Buildroot `epass_drm_app` package installs it during the image build.

## Entry Conditions for `.profile`

`/etc/inittab` logs in as root on `tty0` through `/bin/autologin`, after which the login shell reads `.profile`.

If the current terminal is not `/dev/tty0`, the script only displays the CRA debug-shell greeting and returns without starting the full-screen main program:

```text
Serial, USB ACM, and other debug terminals
    → retain an interactive shell

Local /dev/tty0 console
    → run the complete device startup sequence
```

## Main Startup Sequence

On `tty0`, `.profile` performs these steps in order:

1. Runs `memcheck` to inspect visible memory.
2. Attempts to mount `/dev/mmcblk0p1` at `/sd`.
3. Records the mount result in `/tmp/sd_mounted`.
4. Checks for `epass_drm_app` in the current directory.
5. Starts `usbctl mtp` if the main program is missing, allowing a computer to transfer files.
6. If the program exists, displays `logo.txt`, the program version, and `/etc/os-release`.
7. Repeatedly launches the main program and performs system actions according to its exit code.

`.profile` uses the relative path `./epass_drm_app` and therefore relies on the post-login working directory being `/root`.

## Main-Program Exit-Code Protocol

| Exit Code | Action Taken by `.profile` |
| --- | --- |
| `0` or any other unhandled value | End the supervision loop |
| `1` | Remount the SD card, wait for two seconds, and restart the main program |
| `2` | Run the `/tmp/appstart` extension-application script generated by the main program, then restart the main program |
| `3` | Probabilistically display a shutdown message, then call `poweroff` |
| `4` | Drain input, run `format_sd`, and restart the main program when it finishes |
| `5` | Mount the boot volume, enter `cra_device_config`, and restart the main program when it finishes |

This table must remain consistent with the `EXITCODE_*` definitions in `drm_app_neo/src/config.h`.

## Random Shutdown Messages

`randomly_show_shutdown_message` in `.profile` displays a shutdown message with a 20% probability, selecting each of these programs with equal probability:

```text
/bin/shutdown_message
/bin/shutdown_message_2
/bin/shutdown_message_3
```

The function name and call paths now match the actual filenames in `/bin/`. The function uses `$RANDOM`, as provided by BusyBox `ash`, to generate the branch values.

## Runtime-Generated Files

The following files are not static contents of this overlay:

| File | Generated By |
| --- | --- |
| `/root/epass_drm_app` | Buildroot package installation |
| `/root/asset.log` | Theme scanner |
| `/root/apps.log` | Application scanner |
| `/tmp/appstart` | Extension-application launch logic from the main program |
| `/tmp/sd_mounted` | `.profile` or `format_sd` |

> [!IMPORTANT]
> `.profile` is part of the login and application-launch chain. After changing an exit code, relative path, or mount rule, also verify `/etc/inittab`, the `/bin/` helpers, and the main program.
